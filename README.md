# 冷凍チョコ ギャラリー

デザインスタイルの見本・特徴・用途・AIへの指示例を確認する、個人用のライブラリです。

## 公開・更新

公開先: https://frozen-choco.github.io/my-gallery/

React＋TypeScript＋Viteで実装しています。編集対象は `src/` と `public/`、`docs/` はViteが生成する公開ファイルです。GitHub Pagesの公開元は引き続き `Deploy from a branch` → `main` → `/docs` です。ビルド結果を含めてpushすると公開されます。`docs/` は直接編集しません。

```sh
npm ci
npm run check
npm test
npm run build
git add src public docs index.html vite.config.ts tsconfig.json package.json package-lock.json README.md AGENTS.md
git commit -m "Update gallery"
git push origin main
```

## 起動

Node.js 22.12以降（推奨は最新の22 LTS）を使います。

```sh
npm ci
npm run dev
```

開発画面は http://127.0.0.1:5173 。`npm run check` はTypeScriptの型チェック、`npm test` は操作・データ取得の回帰テストです。`npm run build` 後の `npm run preview` で本番ビルドを確認できます。GitHub Pagesと同じサブパスで確認する場合は `node server.mjs` を実行し、http://127.0.0.1:4173/my-gallery/ を開きます。

## 機能

- 日本語・英語の共通見本を使い、構図・装飾を個別に設計したHTML/CSS見本
- ゲームUI：黒地・白枠、青い窓、携帯機モノクロ、羊皮紙、金属、ダークファンタジー、ホログラム、CRT、赤黒グラフィック、ネオン、柔らかな角丸、ミニマルのスタイル見本
- キーワード検索、印象別フィルター、名前順の並べ替え、グリッド／リスト表示
- 特徴・用途・注意点と、編集してコピーできるAIへの指示例
- モバイル対応、キーボード操作、動きを減らす設定への対応

モーションは表示中のカードで自動ループ再生され、停止ボタンや秒数は表示しません。見本内は文字を使わず、浅い溝でつながる四角い板チョコ・無地の赤い包み紙・簡略化した銀紙で表現します。順番に表示する見本は、小さな板チョコが時間差で現れます。フリップは表面・裏面・側面のある立体で表から裏へ一周します。チョコは右に12度傾け、枠幅の24%に縮小しています。移動と揺れは枠の幅を基準にして、小さな見本でも振幅を保ちます。効果に応じて約2〜3秒台の周期とし、パルスは静止時間なしの1.4秒周期です。ループは効果ごとに設計しています。浮き上がりは上で1.6秒静止して戻り、フェードは滑らかに現れて消えます。スライドは左から中央に入り、静止後に右へ抜け、枠外で左へ戻ります。ズームは点から実寸へ拡大して静止後、枠を覆うまで拡大し、縮小せず点へ切り替えます。パルス・シェイク・バウンスは往復自体が効果なので維持します。画面外や非表示タブでは再生位置を保って休止し、見本領域とタイトルのどちらからも詳細を開けます。動きを減らす設定では静止表示になります。トランジションは昼と夜の共通風景を使い、カット・ディゾルブ・暗転・白転・横ワイプ・縦ワイプ・アイリス・ブラインド・スライド・プッシュ・ズーム・ぼかしを自動再生します。前後の映像を静止して見せ、同じ効果で交互に切り替えます。文字や再生操作は見本内に置きません。動きを減らす設定では2つの風景を左右に静止表示します。

## 編集

- `src/App.tsx`：カテゴリ、検索、絞り込み、ページ分割、表示形式
- `src/components/`：カード、詳細ダイアログ、3Dビューア、見本表示
- `src/catalog/data.ts` / `samples.ts`：デザインスタイルの情報・見本・指示例
- `src/catalog/games.ts` / `motion.ts` / `transitions.ts`：各ジャンルの情報・見本
- `src/catalog/models.ts`：外部モデルカタログの取得・検証
- `src/styles/`：既存の見た目とCSSアニメーション
- `public/`：アイコン、保存済みモデルカタログ、GitHub Pages設定
- `src/test/`：検索、1,000件ページ分割、詳細、コピー、3D入力、カタログ取得のテスト
- `index.html` / `src/main.tsx`：ページの入口

新しいスタイルは `styles` に情報を追加し、そのIDをクラス名としてCSSを追加します。文言は `src/catalog/samples.ts` の共通部品から使い、スタイルごとに構図・装飾を設計します。一覧・詳細は同じ見本を呼び出します。見本は「サンプル」「Sample」のみで、件数やサイト固有の文言を含めません。配色だけの差分にせず、各様式の強みが出る文字組みや情報配置を使ってください。別ジャンルを増やす際は、モーションの再生・停止やトランジションの時間軸など、ジャンル固有のプレビューを追加できます。

見本は特定の企業・製品の画面をコピーしたものではなく、このライブラリのための架空のUIです。分類には歴史的様式・視覚効果・レイアウト手法が混在します。配色と用途は編集上の提案で、必須の定義ではありません。

フォントはGoogle Fontsを読み込みます。ネットワークにアクセスできない場合はシステムの書体で表示します。見本自体は外部画像を必要としません。

ゲームUIは画面の用途ではなく、見た目の様式で分類します。共通文言は「サンプル」「Sample」のみ。様式の違いが出る枠・文字・素材・構図を使い分けます。名称は制作に使うための記述的なラベルで、すべてが正式な様式名というわけではありません。

モーション見本の背景は共通色です。浮き上がり・下線・円形ゲージは標準順で隣り合うように並べます。名称は動きの種類で統一し、ホバーなどの適用条件とは分けます。バウンスは加速する落下、減速する上昇、減衰する跳ね返り、着地の潰れと影を組み合わせています。

効果と関係のないフェードはリセットに使いません。下線・円形ゲージ・順番に表示では `motion-cut` が表示を段階的に切り替え、無表示区間に入ってから開始状態へ戻します。フェードや波紋など透明度そのものが効果である見本のみ、不透明度をアニメーションします。

## 3Dモデル

`#models` は `Frozen-Choco/low-poly-models` の `main/catalog.json` を閲覧時に取得します。モデルを追加する際は、同リポジトリのカタログと `assets/{category}/{id}/` 内の `preview.jpg`、`back.jpg`、`{id}.glb`、`{id}.blend` を更新してください。サイト側の再公開は不要です（開いているページは再読み込み）。外部リポジトリへの書き込みは行いません。

- `src/catalog/models.ts`：カタログ取得・データ検証
- `src/components/ModelPreview.tsx`：カード・詳細・写真・3D・ダウンロードリンク
- `src/styles/models.css`：モデル一覧と詳細の表示
- `public/models-catalog.json`：取得失敗時に使う保存済みカタログ。モデル追加時の必須更新ではありません。

一覧の取得に失敗した場合は保存済みカタログを表示し、再読み込みを案内します。画像とダウンロードファイルは配布元へ直接リンクするため、配布元の通信状態に依存します。名称などの外部テキストはエスケープし、カテゴリとIDはパスとして安全な文字に限定しています。

モデル一覧は正方形の小さなカードで表示し、1ページ60件に制限します。検索・カテゴリ・並べ替えは全カタログを対象とし、条件変更時は1ページ目に戻ります。画像は表示ページのみ生成し、遅延読み込みします。

モデル詳細は3D表示を初期表示とし、ドラッグ・矢印キーによる回転、ホイール・ピンチによる拡大縮小、視点リセット、正面／背面写真の切り替えに対応します。`src/components/ModelPreview.tsx` が詳細を開いたときだけ `@google/model-viewer` 4.4.0（Apache-2.0、jsDelivr配信）と対象GLBを読み込み、閉じるとビューアを破棄します。読み込みエラー・タイムアウト時は再試行と写真表示を利用できます。ライブラリの公式資料：https://modelviewer.dev/docs/

検索・一覧・ダイアログはReactで管理します。既存の見本の構図を維持するため、リポジトリ内の固定HTML/SVG見本のみ `Specimen` に渡します。外部のモデル名などはReactのテキストとして描画し、HTMLには挿入しません。モーションの監視と3Dビューアは部品の終了時に解除します。

## アクセス計測（GA4）

`src/analytics.config.json` の `measurementId` に、このサイトのウェブデータストリームの測定ID（`G-…`）を設定してビルドします。IDが空の場合、開発サーバー、localhostなど本番以外のホストではGoogleのタグを読み込まず、計測しません。測定IDは公開用識別子であり、管理画面を閲覧する権限や秘密鍵ではありません。

管理画面はGoogle Analytics側で確認します。アクセス権を本人だけにし、サイトには統計表示や管理リンクを置きません。任意のGoogleシグナル・広告パーソナライズはコード側で無効にしています。

プロパティ名は `frozen_choco_gallery`、ウェブストリーム名は「冷凍チョコ ギャラリー」です。サイドバーの「プライバシー」から計測内容を確認でき、このブラウザの計測を停止できます（`gallery-analytics-disabled=1`をローカル保存）。自分の閲覧を除外したい場合もこの設定を使えます。

| イベント | タイミング | 内容 |
| --- | --- | --- |
| `page_view` | 初期表示・カテゴリ切り替え | `/my-gallery/styles`、`/my-gallery/models`などの仮想パスと日本語タイトル |
| `select_content` | 見本・モデルの詳細を開く | `content_type`（カテゴリ）、`item_id`（コンテンツID） |
| `model_download` | GLB・Blendリンクをクリック | `item_id`、`file_format`（glb/blend） |

ダウンロードはクリック数であり、転送完了数ではありません。検索文字列や編集した指示文は送信しません。検索・ソート・ページ分割・詳細を閉じる操作はページビューに数えません。

GA4管理画面の「データストリーム → ウェブ → 拡張計測機能 → ページビュー → 詳細設定」で「ブラウザの履歴イベントに基づくページの変更」をオフにしてください。`send_page_view: false`だけでは履歴変更による自動ページビューを止められず、手動計測と重複します。詳細・ダウンロードの分析にはイベントスコープのカスタムディメンション `content_type`、`item_id`、`file_format`を登録します。自動の`file_download`とは別名なので、モデルのクリック数には`model_download`のみを使います。

公式資料：https://developers.google.com/analytics/devguides/collection/ga4/views?hl=ja
